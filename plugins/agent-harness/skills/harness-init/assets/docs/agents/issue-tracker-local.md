# Issue tracker: local files

Work is tracked as markdown files under `.scratch/<feature>/`, one file per issue: `.scratch/<feature>/issues/NN-<slug>.md`,
numbered in dependency order. Each file starts with `Status:` and `Blocked by:` lines. Commit them with the code.

Plans name their issue file in `Ticket:` (e.g. `Ticket: .scratch/<feature>/issues/01-<slug>.md`).
