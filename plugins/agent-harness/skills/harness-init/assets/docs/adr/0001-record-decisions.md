# 0001 — Record architecture decisions as one file per ADR

**Status**: accepted · **Date**: <YYYY-MM-DD> · **Source**: harness setup

We record decisions that are hard to reverse, surprising without context, and the result of a real trade-off,
one per file in `docs/adr/`, indexed in `docs/DECISIONS.md`, so agents and people can find the *why* behind the code.

## Agents should know

Before changing an area, read the ADRs listed for it in `docs/DECISIONS.md`. If your change contradicts one, say so explicitly.
